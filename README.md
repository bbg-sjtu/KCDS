# KCDS #

This is the codebase for the KCDS method.

## 📁 Repository Structure

- **`EF+CNF/`** - Code for training and testing Euclideanizing Flows with Neural ODEs on the LASA 2D dataset
- **`EF+CNF+3D/`** - Code for training and testing Euclideanizing Flows with Neural ODEs on the LASA 3D dataset  
- **`EF+CNF+FMAug+KCanyon/`** - Code for training and testing KCDS with Neural ODEs and FM enhancements on the LASA 2D dataset
- **`EF+CNF+FMAug+KCanyon+3D/`** - Code for training and testing KCDS with Neural ODEs and FM enhancements on the LASA 3D dataset
- **`Media/`** - Experimental videos (see below)
